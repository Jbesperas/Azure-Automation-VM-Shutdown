
# Azure Automation - VM Shutdown

This repository contains my documentation for our Microsoft Azure Automation practical activity.

In this activity, I learned how to use Azure Automation to manage a virtual machine through a runbook and schedule.

## What I Did

- Created an Automation Account in Microsoft Azure
- Imported the StopAzVMs runbook
- Configured the runbook for my Azure VM
- Published the runbook
- Created a schedule for the automation
- Configured the required permissions

## Challenges I Encountered

At first, the automation did not successfully shut down the virtual machine because of permission issues.

After troubleshooting and assigning the required role, I was able to execute the runbook and stop the VM.

## Results

I successfully executed the automation runbook and stopped the virtual machine.

The screenshots showing the configuration and final output are included in my documentation.
